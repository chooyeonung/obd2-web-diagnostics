# OBD_CAN_ESP32_V2 케이스 (초안 v1)

외형 약 78.4 × 42.4 × 30mm · 상하 2피스 · M2.5 나사 4개로 리드+PCB+베이스 동시 체결

## 구조

- **베이스**: PCB가 나사 보스 4개(높이 8.5mm) 위에 안착. 뒷면 부품(D1·Q1·TP)과
  J1 커넥터 공간 확보. 오른쪽 벽에 J1 케이블 개구 + 커넥터 하우징 받침 턱
  (케이블을 뽑을 때 힘이 납땜부가 아닌 케이스에 걸리도록)
- **리드**: 분리면 = PCB 윗면. 오른쪽 벽에 USB-C 개구(데브킷 플래시/디버깅용),
  상단에 벅 컨버터 방열 슬롯. 나사 기둥이 PCB를 위에서 눌러 고정
- **왼쪽 내부 5mm 여유**: 데브킷 WROOM 안테나 돌출 공간 (금속 부착 금지)
- 조립: M2.5 × 25mm 접시머리 나사 4개가 리드 → PCB 구멍(2.7mm) → 베이스 보스(셀프태핑) 순으로 관통

## 실측 후 조정할 파라미터 (obd2_case.scad 상단)

| 파라미터 | 현재값(추정) | 실측 방법 |
|---|---|---|
| `H_BOT` | 8.5 | 보드 뒷면에서 J1 하우징 바닥까지 + 1mm |
| `H_TOP` | 16 | PCB 윗면에서 데브킷 최고점(USB 커넥터)까지 + 2mm |
| `USB_Z0`/`USB_Z1` | 9.5/15.5 | PCB 윗면 기준 데브킷 USB-C 상하 위치 |
| `USB_Y0`/`USB_Y1` | 7/29 | 두 USB-C 포트의 좌우 범위 |

값 수정 → OpenSCAD에서 열기 → part="base"/"lid"로 각각 STL 내보내기.

## 출력 가이드

- 재질: **PETG / ABS / PA12(나일론)** — 차량 실내 온도 때문에 PLA 금지
- 방향: 베이스·리드 모두 개구부가 위로 오게(뒤집힌 상태 그대로) 출력, 서포트 불필요
  (USB/J1 개구는 브리지 15mm 이하라 서포트 없이 출력됨)
- 레이어 0.2mm, 벽 3라인, 인필 20%+
- JLC3DP 주문 시: PA12(MJF) 회색 권장

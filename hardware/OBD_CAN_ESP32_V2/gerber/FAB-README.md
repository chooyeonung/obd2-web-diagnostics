2. 미리보기에서 64×36mm, 2층, 앞/뒷면 패턴 확인

## 주문 전 확인할 것

- **Q1 부품 확정**: 회로도 값이 `Q_PMOS_GDS`(범용 심볼)입니다. BOM에는 SUD50P06-15-GE3(C141584)을 넣어뒀습니다. 저렴한 대안은 HYG120P06LR1D(C2844410). 회로도 값도 실제 품번으로 바꿔두세요.
- **R3는 실장 금지(DNP)**: 차량 CAN 버스에 이미 종단저항이 있습니다. CPL에서 제외했습니다.
- **J3/J4 헤더**: 데브킷을 꽂을 암헤더(2.54mm 1×22) 2개는 BOM에 품번을 넣지 않았습니다. 직접 구매하세요.
- **D1(SM8S24A) 재고**: LCSC 재고가 1,000개 미만이고 제조사별로 가격이 3배까지 차이납니다. 주문 시점에 확인 필요.
- **R12(182k) 재고**: 모든 소스가 5,000개 미만입니다. 부족하면 C163428(Yageo) 또는 180k로 대체 가능(스위칭 주파수 약 505kHz로 미세 변동).
- **L1 Isat 3.5A**: 계획서에는 4A로 적었지만 실제 부하는 0.8A 이하이므로 충분합니다.

## 조립 시 참고

- 부품 위치는 `docs/assembly-front.svg` / `docs/assembly-back.svg` 참조 (실크스크린에 참조번호가 없습니다)
- 뒷면 대형 부품(D1 TVS, Q1 MOSFET, J1 커넥터)을 먼저, 앞면 SMD를 나중에
- U2 열패드는 뒷면 열비아 6개를 통해 인두로 납을 흘려넣을 수 있습니다
- **J1 커넥터 몸통이 보드 오른쪽으로 6.8mm 돌출**합니다. 케이스에서 몸통을 받쳐주도록 설계하세요.

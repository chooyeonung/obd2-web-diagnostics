# 보드 첫 통전 & 검증 절차서 (V2 PCB 기준)

> 구판(만능기판+모듈 벤치)은 폐기. 이 문서는 JLCPCB 조립 보드 기준이다.
> **원칙: 각 단계를 통과하기 전에는 다음 단계로 넘어가지 않는다.**

## 준비물

- 조립된 V2 보드, ESP32-S3-DevKitC-1-N8R8, 멀티미터
- 12V 전원 (어댑터 1A 이상, 또는 차량)
- 손납땜 부품: Q1(FET), J1(XH 커넥터), 핀헤더소켓 2개, D1(TVS — 상시 운용 전 필수)
- 인두 + 실납 + 플럭스

## 0단계 — 손납땜 (통전 전)

- [ ] 핀헤더소켓 1×22 두 개를 J3/J4에 납땜 (데브킷을 소켓에 꽂은 채 위치 맞춰 납땜하면 정렬이 쉬움 — 단, 납땜 중 데브킷 과열 주의, 양끝 핀만 먼저)
- [ ] Q1 납땜: 탭(드레인)이 보드 패드 방향. 플럭스 바르고 다리 → 탭 순서
- [ ] J1 납땜 (스루홀)
- [ ] D1은 이 단계에서 생략 가능 (실차 상시 운용 전에는 필수 장착)
- [ ] 육안 검사: 브리지/냉납, 특히 Q1 주변

## 1단계 — 전원부 단독 (데브킷 꽂지 말 것!)

- [ ] 멀티미터 도통 모드: TP6(GND)–TP4(+5V) 간 단락 아닌지 확인 (삐 소리 나면 중단)
- [ ] J1으로 12V 인가 (XH 하네스 1·2번 = VBAT/GND — 조립도면 참조)
- [ ] TP1 (VBAT_OBD) ≈ 12V
- [ ] TP2 (VBAT_FUSED) ≈ 12V (F1 통과)
- [ ] TP3 (VBAT_PROT) ≈ 12V보다 0~0.3V 낮음 (Q1 통과 — 0V면 Q1 방향/납땜 확인)
- [ ] **TP4 (+5V) = 5.0V ± 0.15V** ← 벅 컨버터 첫 실증 포인트
- [ ] U2·L1 발열 확인 (무부하에서 미지근 이하)
- [ ] 12V를 역극성으로 인가 → TP3 = 0V (역접속 보호 동작) → 원상복구
- [ ] 10분 방치 후 재측정

## 2단계 — 데브킷 단독 (보드와 분리, USB만)

- [ ] USB-C로 PC 연결, `idf.py set-target esp32s3 && idf.py build flash monitor`
- [ ] 로그: `SoftAP started`, `HTTP/WS server started`
- [ ] WiFi `OBD2-DIAG`(pw `obd12345`) 접속 → `http://192.168.4.1/` 콘솔
- [ ] `ATZ` → `ELM327 v1.5 (OBD2-DIY)` / `010C` → `NO DATA` (CAN 미연결이므로 정상)

## 3단계 — 결합 (USB 분리 상태에서)

- [ ] 데브킷을 소켓에 장착 (안테나가 보드 왼쪽 밖을 향하도록 = USB 커넥터가 오른쪽)
- [ ] TP5 (+3V3) ≈ 3.3V 확인
- [ ] J1으로 12V 인가 → 부팅·WiFi·콘솔 재확인
- [ ] 12V 입력 전류 확인 가능하면 50~150mA 수준
- [ ] ⚠️ USB와 12V 동시 인가 금지

## 4단계 — 실차

- [ ] OBD 커넥터 배선: 16(+12V)→하네스 VBAT, 4·5(GND)→GND, 6(CAN-H)→TP7 라인, 14(CAN-L)→TP8 라인 (핀맵은 docs/wiring-guide.svg)
- [ ] 시동 OFF·키 ON에서 연결 → `ATZ` 확인
- [ ] `0100` → `41 00 ...` = 차량 통신 성공 🎉
- [ ] `010C`(RPM)·`0105`(수온)·`0902`(VIN) → 시동 후 RPM 변화 확인
- [ ] 웹앱 https://chooyeonung.github.io/obd2-web-diagnostics/ → 자동 감지 → 대시보드 동작

## 문제 발생 시

| 증상 | 우선 확인 |
|---|---|
| TP4가 0V | TP3부터 역추적 (F1? Q1?), U2 납땜 |
| TP4가 5V 아님 | R10/R11 값, FB 배선 — 측정값 알려주면 원인 분석 가능 |
| `0100` NO DATA | CAN-H/L 뒤바뀜, GND 공통 여부, 차량 프로토콜(2008년 이후 국산차는 CAN) |
| 부팅 반복 | TP4 전압 강하 확인, USB 동시 인가 여부 |
| WiFi 약함 | 데브킷 방향(안테나가 키프아웃 쪽인지) |

결과는 이 파일에 기록해서 커밋.

# PCB V2 계획 — C안: 온보드 벅 + 데브킷 하부 배치 (목표 66×36mm)

V1(69×72) 대비 면적 −56%. 핵심: LM2596 모듈 제거 → SMD 벅 회로, 모든 SMD를 데브킷 아래(헤더 사이 22.86mm 폭, 높이 여유 ~8.5mm)로.

## 1. 벅 컨버터 회로 (LM2596 모듈 대체)

**IC: TI TPS54360B** (SO-8 PowerPAD) — 입력 4.5~**60V**, 3.5A, 비동기 벅.
60V 내압이라 SM8S24A 클램핑 전압(~39V)과 로드덤프에 마진 충분. LCSC/JLC 재고 안정.

| Ref | 값/부품 | 패키지 | 비고 |
|---|---|---|---|
| U2 | TPS54360BDDA | SO-8 PowerPAD | 열패드 → GND 비아 4개 이상 |
| C10,C11 | 2.2µF 100V X7R ×2 | 1210 | VIN 입력 (VBAT_PROTECTED) |
| C12 | 100nF 100V | 0805 | VIN 고주파 |
| C13 | 100nF 25V | 0603 | BOOT–SW |
| D10 | B360A (60V 3A 쇼트키) | SMA | 캐치 다이오드, SW–GND |
| L1 | 10µH 4A 실드형 (예: SWPA6045S100MT) | 6.0×6.0×4.5mm | SW → VOUT |
| C14,C15 | 22µF 16V X7R ×2 | 1206 | 출력 (+5V) |
| R10 | 52.3kΩ 1% | 0603 | FB 상단 (VOUT→FB) |
| R11 | 10.0kΩ 1% | 0603 | FB 하단 (FB→GND) → 5.0V |
| R12 | 182kΩ 1% | 0603 | RT/CLK → GND, fsw≈500kHz |
| R13 | 8.06kΩ | 0603 | COMP 직렬 R |
| C16 | 3300pF | 0603 | COMP 직렬 C (R13와 직렬로 COMP→GND) |
| R14/R15 | 365k / 88.7k (선택) | 0603 | EN 분압 — UVLO ≈8.6V 시작 (크랭킹 채터 방지). 생략 시 EN 플로팅 |

- 배선: VIN 루프(C10/C11–IC–D10) 최소화, SW 노드 면적 최소, FB 트레이스는 L/SW에서 멀리
- VOUT(+5V) → 데브킷 5V 핀(J3-21), 부하 여유: ESP32 WiFi 피크 ~0.6A ≪ 3.5A
- 점유 면적 ≈ 18×16mm → 데브킷 하부 수납 가능 (최대 높이 L1 4.5mm < 8.5mm)

## 2. 보드 구성 (66×36)

```
 ← 66mm →
┌────────────────────────────────────────────┐
│ [안테나 돌출/구리금지 8mm]   ESP32-S3 DevKitC   [USB 엣지] │ ↑
│ ┌헤더row───────────────────────헤더row┐      │ 36mm
│ │  (하부) CAN존 │ 벅존 │ 입력보호존        │      │
│ └──────────────────────────────────┘      │
│ [JST-XH 6P]  [TP열 1.5mm]                  │ ↓
└────────────────────────────────────────────┘
```

- **데브킷 방향**: 안테나(WROOM 끝) = 보드 왼쪽 **엣지 밖으로 2~3mm 돌출** 또는 그 영역 전층 구리 금지. USB 커넥터 = 오른쪽 엣지에 맞춤(케이블 접근)
- **하부 존 배치** (모두 높이 ≤4.5mm라 간섭 없음):
  - 입력보호존(USB쪽 끝): F1(1812) → SM8S24A → Q1(TO-252) + R1 + D2
  - 벅존(중앙): 위 1번 회로
  - CAN존(커넥터쪽): U1 + C1(U1 VCC 2mm 이내!) + R2 + R3(DNP)
- **커넥터**: 터미널블록 → **JST-XH 6P 사이드엔트리**(S6B-XH-A, 16.5×7mm) 하단 긴 변 엣지. D3(NUP2105L)는 커넥터 3mm 이내
- **TP**: D1.5mm SMD 패드로 축소, 하단 스트립에 일렬
- CAN_H/L: 차동 페어로 커넥터→D3→U1 최단 라우팅, 스터브 최소

## 3. V1에서 가져갈 수정사항

- [ ] **D2 제너 180° 반전** (K→VBAT_PROTECTED/소스, A→게이트) — V1 치명 이슈
- [ ] C1을 U1 VCC 핀 옆으로
- [ ] CAN_TX/RX = J3 핀10/11 = **GPIO17/GPIO18** (DevKitC-1 공식 핀맵 기준 — 실물 실크로 최종 확인)
  → 펌웨어 `twai_bus.h` GPIO17/18로 변경 완료. 모든 문서도 17/18로 통일함

## 4. 발주 체크 (JLCPCB 기준)

- 2층, 1oz, 보드 66×36, 최소 트랙/갭 0.2mm면 충분
- TPS54360B·B360A·인덕터는 LCSC 파트넘버로 BOM 지정 (SMT 조립 시)
- 데브킷 헤더는 스루홀 → 이코노미 SMT + 수납땜 또는 스탠다드 조립
